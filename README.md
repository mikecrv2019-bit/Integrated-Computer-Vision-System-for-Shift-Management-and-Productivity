# AssistantTrack 4D - Sistema de Control Laboral con Computer Vision

Aplicación web moderna para gestión de empleados, control de turnos y análisis de costos con Computer Vision.

## 🚀 Estructura del Proyecto

```
├── frontend/          # Interfaz web (Next.js + React)
├── api/              # Backend (FastAPI)
├── vercel.json       # Configuración despliegue Vercel
└── README.md         # Este archivo
```

## 📋 Requisitos

- Node.js 18+
- Python 3.11+
- Git

## 🛠️ Instalación Local

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd api
pip install -r requirements.txt
python src/main.py
```

## 🌐 Despliegue en Vercel

El proyecto está configurado para desplegarse automáticamente en Vercel:

1. Push a GitHub
2. Vercel detecta los cambios
3. Build automático
4. Deploy en vivo

## 📊 Features

- ✅ Gestión de empleados
- ✅ Control de turnos (Check-in/Check-out)
- ✅ Control de Overtime
- ✅ Motor de Alertas
- ✅ Análisis de Costos
- ✅ Reportes en Excel/CSV
