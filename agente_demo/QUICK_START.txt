🚀 INICIAR EN 5 PASOS (5 MINUTOS)

PASO 1: Instalar Dependencias
------------------------------
Abre terminal/cmd en esta carpeta y ejecuta:

    pip install -r requirements.txt

PASO 2: Agregar Imágenes
------------------------
Copia imágenes de personas (JPG/PNG) a la carpeta:

    demo_images/

Ejemplo: demo_images/persona1.jpg, demo_images/persona2.jpg

PASO 3: Ejecutar Agente
----------------------
En la terminal, ejecuta:

    python run_agent.py

PASO 4: Ver Resultados
----------------------
Los resultados se guardan en:

    outputs/

Archivos generados:
  - faces_*.jpg         (imágenes con rostros detectados)
  - resized_*.jpg       (imágenes redimensionadas)
  - grayscale_*.jpg     (imágenes en escala de grises)
  - analysis_report.json (reporte de análisis)

PASO 5: (Opcional) Compilar a .exe
---------------------------------
En Windows, ejecuta:

    build_exe.bat

El archivo run_agent.exe se genera en la carpeta dist/

🔧 TROUBLESHOOTING

Error: ModuleNotFoundError
→ Ejecuta: pip install --upgrade opencv-python

Error: DLL load failed
→ Ejecuta: pip install opencv-python-headless

Error: No se encuentran imágenes
→ Coloca imágenes en demo_images/ y ejecuta de nuevo
